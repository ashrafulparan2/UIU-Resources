# Week 3 OOP Concept Demos

These are additional demo files created **without changing your existing code**.

## Files and Concepts

- `ConstructorOverloadingAndCopyDemo.java`  
  Demonstrates default constructor, parameterized constructors, and copy constructor.

- `PointArrayDemo.java`  
  Demonstrates object creation and array of objects.

- `CircleCalculationsDemo.java`  
  Demonstrates class methods (`area`, `circumference`) and object initialization.

- `StaticMembersDemo.java`  
  Demonstrates static vs instance members and static method usage.

## Compile and Run (PowerShell)

```powershell
javac ConstructorOverloadingAndCopyDemo.java
java ConstructorOverloadingAndCopyDemo

javac PointArrayDemo.java
java PointArrayDemo

javac CircleCalculationsDemo.java
java CircleCalculationsDemo

javac StaticMembersDemo.java
java StaticMembersDemo
```
